Connect Firebase to finish setup

This portal needs a Firebase project. Open index.html, find FIREBASE_CONFIG near the bottom, and paste your project's web config. See SETUP.md for the full checklist.

  1. Firebase console → Project settings → Your apps → Web app → copy the firebaseConfig values.
  2. Authentication → Sign-in method → enable Email/Password and Anonymous.
  3. Firestore Database → create database → Rules → paste firestore.rules.
  4. Deploy, then open /admin to create the first administrator.
